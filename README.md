# 🥊 NETA FIGHTERS — Online Political Meme Fighting Game

A **Tekken-style** 1v1 fighting game. Pick a fighter. Each fighter is a **fake, funny** version of a world political type. Each has **4 special moves**. Play **online, anytime**.

> Satire. All characters, names, and places are **fictional** look-alikes for comedy only.

## What is special
- 🧍 **Characters are the main attraction** — built one by one, with care, in Blender.
- 🎯 **Strategic combat** — every fighter has strengths, weakness, 4 specials.
- 🌐 **Online play** — fight friends or world anytime.
- 🎨 **Good graphics + animations** — real 3D models + motion.

## Folders
- `docs/` — game + tech + combat design
- `characters/` — one folder per fighter (design + Blender + data)
- `characters/_template/` — copy this to start a new fighter
- `stages/` — fight backgrounds (Senate, warship, petrol pump, Parliament, ring...)
- `assets/` — shared art, audio
