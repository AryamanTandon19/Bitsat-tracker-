# 🌍 Stages — Fight Backgrounds

> Each stage has a mood, hazards, and edge type (wall = wall combos, open = ring-out feel).

## 1. Boxing Ring 🥊
- Mood: bright lights, crowd cheering.
- Edges: ropes = walls (wall bounce combos).
- Build first (simplest).

## 2. Big Parliament 🏛️ (India, fake)
- Mood: grand hall, big dome, flags.
- Edges: pillars as walls.

## 3. The Senate 🏛️ (US, fake)
- Mood: marble, blue carpet, eagle motifs (fake).
- Edges: closed walls.

## 4. Warship / Destroyer 🚢
- Mood: steel deck, sea, wind, sunset.
- Edges: OPEN water = ring-out risk (high strategy).
- Hazard: sliding crates.

## 5. Indian Petrol Pump ⛽
- Mood: dusty road, oil drums, parked scooters, dhaba.
- Edges: half-open.
- Hazard: oil puddle = slip.

## Build note
- Start gray-box (simple shapes), then add art.
- Each stage = own folder later with `.blend` + textures.
